# Bio-informatics-fall-project
Computational analysis of unknown sequence
Fatima Nabeel (Reg. No. 04032213029)
An unknown nucleotide sequence was provided for analysis. Comprehensive DNA, RNA, and protein analyses were performed using various bioinformatics tools. The DNA sequence was translated into an amino acid sequence, followed by multiple sequence alignment and interaction analysis of the target protein with related proteins. DNA sequence alignment, RNA secondary structure stability, protein secondary structure, domain identification, physicochemical properties, phylogenetic analysis, and subcellular localization were systematically evaluated.Based on the combined results of these analyses, it was concluded that the unknown sequence corresponds to the  Eukaryotic synthetic construct chromosome 17 protein , located on chromosome 17. Tools such as NCBI BLAST, ORF Finder, ExPASy, UniProt, Vienna RNA Web Server, ClustalW, Pfam, PredictProtein, CELLO, TargetP, STRING, and other bioinformatics resources were utilized throughout the study.
